## Website für DLBUXPWP01

Eine kleine Lernwebseite über Trading Card Games.

## Trading Card Games

- Legends of Runeterra (LoR)
- Magic: The Gathering (MTG)
- Yu-Gi-Oh (YGO)

## Struktur

- `frontpage.html` - Startseite
- `src/` - HTML-Seiten für Spiele und Decklisten
- `img/` - Bilder und Assets für die Spiele
- `src/legal.html` - Impressum
